# n8n-nodes-gemini-image

Community node for [n8n](https://n8n.io) to generate images using Google Gemini (Imagen 4).

This package exposes a single node **Gemini Image Generate** which uses the native `googlePalmApi` credentials from n8n.

## Development

Install dependencies and build the project:

```bash
npm install
npm run build
```

The compiled node will be available under `dist/`.
